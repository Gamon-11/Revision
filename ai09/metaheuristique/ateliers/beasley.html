Atelier Beasley : découper un tour géant

« Route first, cluster second » : on garde l'ordre du tour géant et on cherche où le couper, par un plus court chemin dans un graphe auxiliaire. Choisis un exercice puis avance avec « Étape suivante » ou les flèches du clavier. Fais l'étape sur ta feuille avant de cliquer.

Graphe auxiliaire

arc (i−1) → j = une tournée qui sert les clients i à j

Carte

La méthode
  1. Numéroter les clients dans l'ordre du tour géant : 1 … n. Sommets 0 … n.
  2. Pour chaque suite i … j qui tient dans un véhicule (charge ≤ Q ou longueur ≤ L), arc (i−1) → j de coût dépôt → i → … → j → dépôt.
  3. Plus court chemin de 0 à n : V(0) = 0, V(j) = min sur les arcs (i−1) → j de V(i−1) + coût.
  4. Remonter les prédécesseurs depuis n : chaque arc du chemin est une tournée.
