Atelier Gillett-Miller + Fletcher

Balayage pour former les clusters, puis heuristique de Fletcher (arêtes les plus courtes d'abord) dans chaque cluster. Choisis un onglet puis avance avec « Étape suivante » ou les flèches du clavier. Fais l'étape sur ta feuille avant de cliquer.

Grille

axe de balayage cluster 1 cluster 2 cluster 3 refusée (sous-cycle)

La méthode
  1. Gillett-Miller (balayage) : calculer l'angle de chaque client vu du dépôt, mesuré depuis l'axe initial dans le sens de rotation. Un point sur l'axe a l'angle 0 et passe en premier.
  2. Prendre les clients dans cet ordre et les ajouter au cluster courant tant que la charge reste ≤ Q. Sinon, fermer le cluster et en ouvrir un nouveau.
  3. Fletcher dans chaque cluster (dépôt inclus) : trier toutes les arêtes par longueur croissante.
  4. Prendre une arête si ses deux extrémités ont un degré < 2 et si elle ne ferme pas un sous-cycle. Seule la toute dernière arête a le droit de fermer le cycle hamiltonien.
  5. S'arrêter quand on a autant d'arêtes que de sommets. Distance totale = somme des tournées.

Ex æquo : quand plusieurs arêtes ont la même longueur, le résultat peut changer selon l'ordre choisi. Ici on départage par numéro (D d'abord, puis 1, 2, …), sauf dans l'onglet « autre départage ». Annonce toujours ta règle sur la copie.
