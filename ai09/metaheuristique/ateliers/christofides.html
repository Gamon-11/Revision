Atelier Christofides : un tour garanti à 1,5 × l'optimum

Arbre couvrant minimal, sommets impairs, couplage minimal, cycle eulérien, raccourcis. Choisis un exercice puis avance avec « Étape suivante » ou les flèches du clavier. Fais l'étape sur ta feuille avant de cliquer.

Graphe

arbre couplage cycle eulérien tour final refusée

La méthode
  1. Arbre couvrant minimal (Kruskal : arêtes par coût croissant, refuser celles qui ferment un cycle).
  2. Repérer les sommets de degré impair dans l'arbre (toujours en nombre pair).
  3. Couplage parfait de coût minimal entre ces seuls sommets impairs.
  4. Arbre + couplage : tous les degrés sont pairs, il existe un cycle eulérien.
  5. Parcourir le cycle eulérien depuis le dépôt.
  6. Raccourcis : sauter les sommets déjà visités. On obtient un cycle hamiltonien.

Garantie : C(T) ≤ 1,5 × OPT si l'inégalité triangulaire est respectée (arbre ≤ OPT, couplage ≤ OPT/2, raccourcis sans allongement).
